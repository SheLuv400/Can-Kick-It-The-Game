# Brand artwork

The game ships a vector recreation of the CAN I KICK IT? logo, drawn in
`src/components/BrandLogo.tsx`.

To use the original artwork instead, save it here as `logo.png`
(`logo.svg`, `logo.jpg` or `logo.webp` also work). The main menu picks it up
automatically on the next build — no code change, and the vector mark stays as
the fallback if the file is ever removed.

Use a transparent PNG at 1600 px wide or larger for crisp scaling on the menu.
